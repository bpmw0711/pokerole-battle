# Pokerole 3.0 線上對戰

朋友之間用的 Pokerole 3.0 單打對戰工具。規則依原書，自動擲骰、判定輪到誰、算傷害，招式與特性的特殊效果用「手動調整」補上。

## 怎麼玩
1. 開啟網頁，輸入名字，到「管理隊伍」建立隊伍。隊伍存在自己的瀏覽器裡；編輯畫面和規則站的隨機產生器一樣（篩選、隨機配點、圓點能力值、剩餘點數），可以用 pokepast.es 格式匯入／匯出寶可夢與整個隊伍。
2. 一個人按「建立房間」，把「邀請連結」或房號傳給對手。
3. 雙方選隊伍、選首發，開始對戰。
4. 房間滿了以後，其他人打開連結會以觀戰模式進入。
5. 重新整理或斷線後，首頁的「我的房間」會列出進行中的房間與輪到誰，按「重新連線」就能回去（清單存在瀏覽器裡，換瀏覽器或清除資料就沒有了，仍可用房號加入）。房主可在清單裡刪除自己的房間；超過一週沒人用的房間可設定每月自動清理，見 [CLEANUP.md](CLEANUP.md)。

規則判定方式與改編見 [RULES-NOTES.md](RULES-NOTES.md)。

## 開發
- `js/engine.js`：規則引擎，對戰狀態由「操作＋擲出的骰面」的紀錄重算。
- `js/moves.js`：招式判讀。
- `js/net.js`：Firebase（匿名登入＋Realtime Database）。
- `js/app.js`：畫面；`js/editor.js`：隊伍編輯；`js/pkcore.js`：與規則站共用的規則、角色卡畫面、匯入匯出（正本在 `site/assets/pkcore.js`，改完執行 `tools/sync_pkcore.bat` 複製過來）。
- `data/db.json`：由規則站專案的 `tools/build_battle_data.mjs` 產生。
- 測試：`node --test test/engine.test.mjs`
- 本機測試兩個玩家：網址加上 `?guest`，每個分頁會用不同的一次性身分。
